Predicting lupus flares from blood gene expression and clinical activity

Systemic Lupus Erythematosus (SLE) is an autoimmune disease that alternates between quiet periods and flares, episodes of increased disease activity that can damage organs. This project uses a Temporal Attention Graph Transformer (TAGT) to estimate the chance that a patient flares at their next visit, from 1,000 whole-blood gene-expression probes plus their current SLEDAI-2K activity score.

Try a prediction See validated results

1 · Gene encoder

1,000 Illumina probes, standardised per probe, are compressed into a 128-dimensional molecular signature. Heavy input dropout keeps the network from memorising noise.

2 · Graph + attention

A graph projection mixes the gene signature, and multi-head attention (8 heads) re-weights it, following the TAGT layout of the original research code.

3 · Clinical fusion

The current SLEDAI-2K score and flare status are encoded and fused with the molecular signature. A classifier then outputs the probability of a flare at the next visit.

Research prototype. Trained on a semi-synthetic dataset (real GSE49454 expression profiles + simulated clinical visits). This tool is for education and research only. It is not a medical device and must not be used to make clinical decisions.

Key findings

    Methodology

    Dataset

    The dataset is semi-synthetic. Gene-expression profiles are real whole-blood transcriptomes from GSE49454 (NCBI GEO, Illumina HumanHT-12; 1,000 probes kept). The longitudinal clinical part is simulated by the repository's preprocessing script: patient visit histories, SLEDAI-2K scores and flare labels. Each simulated visit is given a randomly chosen real expression profile. This gives consecutive-visit pairs from simulated patients. The target is whether a flare occurs at the next visit; the flare rate is .

    Inputs

    • Gene expression at the current visit (1,000 probes, z-scored using training-fold statistics only)
    • Current SLEDAI-2K score (scaled ÷ 20)
    • Current flare status (0 / 1)

    Training

    AdamW (lr 1e-3, weight decay 0.05), 15 epochs, batch size 32, class-balanced BCE loss, Gaussian-noise augmentation (σ = 0.1), input dropout 0.7 and gradient clipping at 1.0.

    Validation protocol

    We use patient-grouped stratified 5-fold cross-validation. All visits from the same patient stay in the same fold, so the model is always tested on unseen patients. Without grouping, visits from the same person leak between training and test sets and inflate the scores.

    Baselines

    • Logistic regression on clinical features only
    • L2-regularised logistic regression on genes + clinical
    • Random forest (300 trees) on genes + clinical

    Limitations

    • Clinical trajectories are simulated and expression profiles are assigned to visits at random, so the genes carry almost no real flare signal. Results demonstrate the pipeline, not clinical validity.
    • Small cohort (100 patients, ~380 visit pairs), so fold-to-fold variance is high.
    • The shipped checkpoint models/best_tagt_model.pt produced near-constant outputs (AUC ≈ 0.50) on this data, so the model was retrained from scratch for this app.
    • Earlier documents in the repository report AUC 0.94. That figure could not be reproduced under leakage-free evaluation.
    • There is no external validation cohort, and no prospective or clinical validation.
